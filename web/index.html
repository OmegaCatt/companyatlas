Firemní soubory a odpovědi

Procházejte dostupné soubory nebo položte dotaz. Počty objednávek vycházejí z databáze; odpovědi nad dokumenty ukazují použité zdroje.

Jak CompanyAtlas pracuje Python, SQL, API a oprávnění

Technologie: Python HTTP server, SQLite, HTML/CSS/JavaScript. OpenAI Responses API slouží jen k souhrnům povolených textových dokumentů; přesné počty a součty objednávek počítá SQL.

Postup: Server ověří ukázkovou roli před výběrem názvů, obsahu i zdrojů. Pro AI dotaz předá pouze povolené úryvky a ověří, že vrácené citáty ve zdrojích skutečně jsou.

Hranice: Účty mají veřejná demo hesla a data jsou fiktivní. Výskyt citátu nedokazuje správnost interpretace; tato ukázka není připravená pro skutečné firemní soubory.

Co tento panel skutečně ověřuje

Osm kontrol se nyní provede nad aktuální fiktivní databází na serveru. Každou rozbalte: ukáže zadání, očekávání, skutečný výsledek a postup. Změněný nebo chybějící referenční podklad může kontrolu záměrně zneplatnit.

Čísla a upřesnění

SQL počty a součet proti známým CSV hodnotám; nejednoznačný zákazník musí vyvolat upřesnění.

Hranice přístupu

Přímý přístup i vyhledávání podle role. Nestačí, že je soubor skrytý v rozhraní.

Samostatné ověřování AI

Tento panel AI nevolá. 50 offline případů a uložené živé běhy jsou popsané zvlášť; citace sama nedokazuje správný závěr.
